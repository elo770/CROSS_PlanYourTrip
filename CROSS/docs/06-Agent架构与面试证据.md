- Vue、Pinia、Express 组成地图、日程、预算和 Agent 工作区。
- DeepSeek 负责结构抽取、咨询回答和操作选择；高德负责 POI 核实。
- 导入、生成、修改和普通问答采用不同决策路径。
- 地图与日程共享正式 Plan，Agent 修改先形成 Proposal，用户确认后才应用并支持撤销。
- Prompt 已拆分为基线版与结构化版。
- 33 项 Node 测试与 80 条离线评测通过（2026-07-17 当前工作区验证）。

### 进行中

### 不可声称

- 未经用户确认的个人职责、业务指标或项目收益。

## Bad Case：日期结构丢失

用户导入第一至第四天的路线后，旧链路先扁平提取地点，丢失 `Day → Activity` 关系；简单天数规则又把“第一天”误当成“玩一天”，导致自然语言回复描述四天而正式 Plan 只有一天。

修复没有停留在 Prompt：

1. 区分总时长与日期序号。
2. 先确定性切分日期块，再让模型抽取块内活动。
3. 建立 `Trip → Day → Activity` Schema 和活动类型。
4. Validator 检查日期、关系和遗漏。
5. 将失败输入沉淀为回归测试和 Eval Case。
